## What is SMARTBOB?

SMARTBOB is an open building automation and smart home system made in Poland, designed for modern wired installations and integration with popular automation platforms. SMARTBOB started as a DIY project developed by automation and electronics enthusiasts and over time became a fully fledged commercial system.

---

## How does it work?

SMARTBOB is one part of a complete building automation system. The controllers act as actuators and input/output modules responsible for physically controlling devices in the building – e.g. lighting, shutters, gates or heating.

The system is designed to work with various automation platforms and not lock the user into a single ecosystem.

SMARTBOB can work with, among others:
- SUPLA
- Home Assistant (ESPHome)
- LOXONE
- AMPIO
- MQTT
- ESP32-based systems

The final functionality depends on the chosen master platform and how the automation is configured. Regardless of the system used, the basic principle stays the same – SMARTBOB physically controls the devices and provides an interface for further automation.

This means you can start the installation before choosing the target smart home platform. You can first do the wiring and mount the SMARTBOB controllers, and only later decide which automation system to use.

## Models and comparison

The SMARTBOB line has three series: **MINI** and **GATE** for smaller tasks, **LITE** as the main house controller and **PRO** for large installations. **R** versions have relay outputs (potential-free, 230 V AC or DC), **D** versions have 24 V MOSFET transistor outputs with PWM for LED strips and 24 V relays. All of them mount on a TH35 rail in the distribution board, and the SM-EXP-16IN expander adds more inputs.
