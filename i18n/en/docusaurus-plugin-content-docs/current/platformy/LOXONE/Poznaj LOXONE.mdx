## The LOXONE platform

Loxone is one of the best-known building automation systems in Europe.
The platform was created for comprehensive control of homes, commercial buildings and industrial facilities.

# The system lets you manage, among others:
- Lighting
- Roller blinds and shutters
- Heating
- Air conditioning
- Ventilation
- Alarm
- Energy monitoring
- Multimedia and audio

:::tip
One of the biggest advantages of Loxone is local processing of the automation logic.
Loxone works very well in buildings, plants, hotels etc.
:::

## SMARTBOB + Loxone
SMARTBOB can extend the functionality of the Loxone system through UDP integration and the Loxone configurator.
Data can be exchanged between the devices in real time. The integration is continuously developed together
with new versions of the SMARTBOB software.

In practice this means SMARTBOB controllers can perform functions
that would normally require additional Loxone modules or devices of other manufacturers.

### SMARTBOBSOFT software
The integration with LOXONE, like the one with AMPIO, is based on the same dedicated SMARTBOB controller software
called **SMARTBOBSOFT**. Unlike the Home Assistant integration (based on ESPHome),
SMARTBOBSOFT is SMARTBOB's own firmware, uploaded directly to the controller.

Current software versions for each SMARTBOB controller model are available in the GitHub repository:
