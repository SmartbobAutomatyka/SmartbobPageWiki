## Technical specification

| Parameter | Value |
|---|---|
| Inputs | 32 |
| Outputs | 22 × relay |
| Output type | AC / DC (potential-free) |
| Analog inputs | 2 (up to 24 V) |
| Communication | LAN, Wi-Fi, RS485, CAN, 1-Wire, I2C |
| Enclosure | 212 × 90 × 59 mm (with connectors: 212 × 116 × 59 mm) |

---
## Power supply parameters

| Parameter | Value |
|---|---|
| Supply voltage | 24 V DC |
| Current consumption (max.) | 0,75 A (18 W) |
| Power cable | LgY 1 mm² |

:::tip
Several SMARTBOB controllers in one installation can share one power supply with sufficient current capacity, but a separate power supply is recommended.
:::

## Software

The SMARTBOB controller is a universal platform – the installed software is stated on the packaging, on the housing or in the order.

- [SUPLA](/platformy/SUPLA/Poznaj%20SUPLA)
- [Home Assistant (ESPHome)](/platformy/HOME%20ASSISTANT/Poznaj%20HOME%20ASSISTANT)
- [LOXONE](/platformy/LOXONE/Poznaj%20LOXONE)
- [AMPIO](/platformy/AMPIO/Poznaj%20AMPIO)
- MQTT
- ESP32-based systems

The configuration depends on the chosen platform.

First start-up and configuration on the chosen platform (SUPLA, Home Assistant, LOXONE, AMPIO): [Platforms – guides](/category/platformy)

## Safe use

Before installation make sure the wires are not live. Installation should only be carried out by a qualified person in accordance with applicable standards. Do not use the controller without a housing or with a damaged housing. Do not exceed the operating parameters – especially the relay load. Some platforms require an external server, cloud or additional software.
