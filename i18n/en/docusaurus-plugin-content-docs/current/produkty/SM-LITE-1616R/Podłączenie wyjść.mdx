## Connecting outputs

Instructions for connecting lighting, roller blinds, control signals and other loads using the controller's
relay outputs.

---
## Relay outputs

The SMARTBOB 1616R controller has 16 relay outputs on 8 green 5-pin plug-in connectors.
The outputs are divided into pairs of 2 relays.

Parameters of a single relay:

| Parameter | Value |
|----------|----------|
| Output type | Potential-free |
| Maximum AC voltage | 230V AC |
| Maximum DC voltage | 30V DC |
| Maximum current | 10A |
| Contact type | NO or NO/NC |

This allows both standard switching of loads and more advanced control circuits
requiring a changeover contact, e.g. roller blind control (with protection against switching on
both motor directions at the same time).

:::tip
Each output can work completely independently and control a different voltage or circuit.
Example configuration:
- Relay 1 → Phase 1 — lighting
- Relay 2 → Phase 2 — lighting
- Relay 3 → Phase 3 — lighting
- Relay 4 + Relay 5 → Roller blind control up/down
- Relay 6 → Gate control signal
- Relay 7 → 24V AC solenoid valve
- Relay 8 → 12V DC contactor coil

Thanks to potential-free relays it is possible to control at the same time:
- 24/230V AC circuits,
- 5/12/24V DC,
- logic signals,
- inputs of other controllers and automation devices.
:::
