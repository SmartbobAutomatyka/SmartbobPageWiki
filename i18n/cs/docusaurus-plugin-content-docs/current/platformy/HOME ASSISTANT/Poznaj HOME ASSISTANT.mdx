## Platforma HOME ASSISTANT

Home Assistant je jedna z nejpopulárnějších open-source platforem pro automatizaci domácnosti na světě.
Umožňuje integrovat tisíce zařízení různých výrobců do jednoho centrálního systému.

# Platforma umožňuje ovládat, monitorovat a automatizovat mimo jiné:
- Osvětlení
- Rolety a žaluzie
- Vytápění
- Klimatizaci
- Větrání
- Alarmy
- Monitoring
- Zařízení IoT
- Fotovoltaické instalace
- Akumulaci energie

SMARTBOB spolupracuje s Home Assistant jako akční řídicí jednotka, systém vstupů a výstupů nebo integrační modul
a umožňuje stavět pokročilé instalace chytré domácnosti založené na různých protokolech a otevřených standardech.

:::tip
Jednou z největších výhod Home Assistant je možnost spojit zařízení mnoha výrobců
do jednoho systému automatizace. Většina funkcí běží lokálně,
takže automatizace nezávisí na cloudových službách.
:::
:::warning
Home Assistant vyžaduje znalost různých programovacích technik a pro začátečníka může být příliš náročný.
:::

## SMARTBOB + Home Assistant

SMARTBOB byl navržen pro snadnou integraci s Home Assistant.
Integrace probíhá pomocí projektu **ESPHome**, který Home Assistant nativně podporuje.
Pro řídicí jednotky SMARTBOB jsme připravili hotové konfigurační šablony ESPHome,
takže spuštění je rychlé a nevyžaduje psaní konfigurace od nuly.

Integrace obvykle probíhá takto:

1. Stáhněte šablonu pro svou řídicí jednotku SMARTBOB a přidejte ji do ESPHOME BUILDER.
2. Doplňte základní síťová nastavení a přizpůsobte ji svým potřebám.
3. Zkompilujte a nahrajte do řídicí jednotky přes USB nebo OTA.
4. Přidejte řídicí jednotku do HOME ASSISTANT přes integraci ESPHOME.
