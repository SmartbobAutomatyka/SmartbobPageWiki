## Die Plattform LOXONE

Loxone ist eines der bekanntesten Gebäudeautomationssysteme in Europa.
Die Plattform wurde für die umfassende Steuerung von Häusern, Gewerbegebäuden und Industrieanlagen entwickelt.

# Das System ermöglicht unter anderem die Verwaltung von:
- Beleuchtung
- Rollläden und Jalousien
- Heizung
- Klimaanlage
- Lüftung
- Alarmanlage
- Energiemonitoring
- Multimedia und Audio

:::tip
Einer der größten Vorteile von Loxone ist die lokale Verarbeitung der Automationslogik.
Loxone bewährt sich sehr gut in Gebäuden, Betrieben, Hotels usw.
:::

## SMARTBOB + Loxone
SMARTBOB kann das Loxone-System über die UDP-Integration und den Loxone-Konfigurator funktional erweitern.
Daten können in Echtzeit zwischen den Geräten ausgetauscht werden. Die Integration wird mit jeder neuen
Version der SMARTBOB-Software weiterentwickelt.

In der Praxis können SMARTBOB-Steuerungen so Funktionen übernehmen,
die sonst zusätzliche Loxone-Module oder Geräte anderer Hersteller erfordern würden.

### Software SMARTBOBSOFT
Die Integration mit LOXONE beruht wie die mit AMPIO auf derselben eigenen Software der SMARTBOB-Steuerungen,
**SMARTBOBSOFT**. Anders als die Integration mit Home Assistant (auf Basis von ESPHome)
ist SMARTBOBSOFT die eigene Firmware von SMARTBOB, die direkt auf die Steuerung geladen wird.
