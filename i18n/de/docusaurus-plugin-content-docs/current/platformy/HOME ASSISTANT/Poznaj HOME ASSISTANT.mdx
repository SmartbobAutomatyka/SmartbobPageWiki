## Die Plattform HOME ASSISTANT

Home Assistant ist eine der weltweit beliebtesten Open-Source-Plattformen für die Hausautomation.
Sie integriert Tausende Geräte verschiedener Hersteller in einem zentralen Verwaltungssystem.

# Die Plattform ermöglicht unter anderem das Steuern, Überwachen und Automatisieren von:
- Beleuchtung
- Rollläden und Jalousien
- Heizung
- Klimaanlage
- Lüftung
- Alarmanlagen
- Überwachung
- IoT-Geräten
- Photovoltaikanlagen
- Energiespeichern

SMARTBOB arbeitet mit Home Assistant als Aktor-Steuerung, Ein-/Ausgabesystem oder Integrationsmodul zusammen
und ermöglicht fortschrittliche Smart-Home-Installationen auf Basis verschiedener Protokolle und offener Standards.

:::tip
Einer der größten Vorteile von Home Assistant ist, dass Geräte vieler Hersteller zu einem gemeinsamen
Automationssystem verbunden werden können. Die meisten Funktionen laufen lokal,
sodass Automationen nicht von Cloud-Diensten abhängen.
:::
:::warning
Home Assistant erfordert Kenntnisse verschiedener Programmiertechniken und kann für Einsteiger zu anspruchsvoll sein.
:::

## SMARTBOB + Home Assistant

SMARTBOB wurde für eine einfache Integration mit Home Assistant entwickelt.
Die Integration erfolgt über das Projekt **ESPHome**, das von Home Assistant nativ unterstützt wird.
Für die SMARTBOB-Steuerungen haben wir fertige ESPHome-Konfigurationsvorlagen vorbereitet,
mit denen die Inbetriebnahme schnell geht und keine Konfiguration von Grund auf nötig ist.

Die Integration läuft in der Regel so ab:

1. Laden Sie die Vorlage für Ihre SMARTBOB-Steuerung herunter und fügen Sie sie im ESPHOME BUILDER hinzu.
2. Ergänzen Sie die grundlegenden Netzwerkeinstellungen und passen Sie sie an Ihre Bedürfnisse an.
3. Kompilieren und per USB oder OTA auf die Steuerung übertragen.
4. Fügen Sie die Steuerung über die ESPHOME-Integration zu HOME ASSISTANT hinzu.
