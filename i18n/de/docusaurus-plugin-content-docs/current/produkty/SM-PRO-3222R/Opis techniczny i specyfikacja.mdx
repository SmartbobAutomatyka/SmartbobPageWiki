## Technische Daten

| Parameter | Wert |
|---|---|
| Eingänge | 32 |
| Ausgänge | 22 × Relais |
| Ausgangsart | AC / DC (potentialfrei) |
| Analogeingänge | 2 (bis 24 V) |
| Kommunikation | LAN, Wi-Fi, RS485, CAN, 1-Wire, I2C |
| Gehäuse | 212 × 90 × 59 mm (mit Steckern: 212 × 116 × 59 mm) |

---
## Versorgungsparameter

| Parameter | Wert |
|---|---|
| Versorgungsspannung | 24 V DC |
| Stromaufnahme (max.) | 0,75 A (18 W) |
| Versorgungsleitung | LgY 1 mm² |

:::tip
Mehrere SMARTBOB-Steuerungen in einer Installation können ein Netzteil mit ausreichender Stromstärke nutzen, empfohlen wird jedoch ein separates Netzteil.
:::

## Software

Die SMARTBOB-Steuerung ist eine universelle Plattform – die installierte Software ist auf der Verpackung, auf dem Gehäuse oder in der Bestellung angegeben.

- [SUPLA](/platformy/SUPLA/Poznaj%20SUPLA)
- [Home Assistant (ESPHome)](/platformy/HOME%20ASSISTANT/Poznaj%20HOME%20ASSISTANT)
- [LOXONE](/platformy/LOXONE/Poznaj%20LOXONE)
- [AMPIO](/platformy/AMPIO/Poznaj%20AMPIO)
- MQTT
- ESP32-basierte Systeme

Die Konfiguration hängt von der gewählten Plattform ab.

Erstinbetriebnahme und Konfiguration auf der gewählten Plattform (SUPLA, Home Assistant, LOXONE, AMPIO): [Plattformen – Anleitungen](/category/platformy)

## Sichere Verwendung

Stellen Sie vor der Montage sicher, dass die Leitungen spannungsfrei sind. Die Montage darf nur von einer qualifizierten Person gemäß den geltenden Normen durchgeführt werden. Verwenden Sie die Steuerung nicht ohne Gehäuse oder mit beschädigtem Gehäuse. Überschreiten Sie die Betriebsparameter nicht – insbesondere die Relaislast. Einige Plattformen erfordern einen externen Server, eine Cloud oder zusätzliche Software.
