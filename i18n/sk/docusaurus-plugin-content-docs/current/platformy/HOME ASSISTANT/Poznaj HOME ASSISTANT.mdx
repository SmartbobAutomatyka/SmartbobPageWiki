## Platforma HOME ASSISTANT

Home Assistant je jedna z najpopulárnejších open-source platforiem na automatizáciu domácnosti na svete.
Umožňuje integrovať tisíce zariadení rôznych výrobcov do jedného centrálneho systému.

# Platforma umožňuje ovládať, monitorovať a automatizovať okrem iného:
- Osvetlenie
- Rolety a žalúzie
- Kúrenie
- Klimatizáciu
- Vetranie
- Alarmy
- Monitoring
- Zariadenia IoT
- Fotovoltické inštalácie
- Akumuláciu energie

SMARTBOB spolupracuje s Home Assistant ako akčná riadiaca jednotka, systém vstupov a výstupov alebo integračný modul
a umožňuje budovať pokročilé inštalácie inteligentnej domácnosti založené na rôznych protokoloch a otvorených štandardoch.

:::tip
Jednou z najväčších výhod Home Assistant je možnosť spojiť zariadenia mnohých výrobcov
do jedného systému automatizácie. Väčšina funkcií beží lokálne,
takže automatizácie nezávisia od cloudových služieb.
:::
:::warning
Home Assistant vyžaduje znalosť rôznych programovacích techník a pre začiatočníka môže byť príliš náročný.
:::

## SMARTBOB + Home Assistant

SMARTBOB bol navrhnutý na jednoduchú integráciu s Home Assistant.
Integrácia prebieha pomocou projektu **ESPHome**, ktorý Home Assistant natívne podporuje.
Pre riadiace jednotky SMARTBOB sme pripravili hotové konfiguračné šablóny ESPHome,
takže spustenie je rýchle a nevyžaduje písanie konfigurácie od nuly.

Integrácia obvykle prebieha takto:

1. Stiahnite šablónu pre svoju riadiacu jednotku SMARTBOB a pridajte ju do ESPHOME BUILDER.
2. Doplňte základné sieťové nastavenia a prispôsobte ju svojim potrebám.
3. Skompilujte a nahrajte do riadiacej jednotky cez USB alebo OTA.
4. Pridajte riadiacu jednotku do HOME ASSISTANT cez integráciu ESPHOME.
