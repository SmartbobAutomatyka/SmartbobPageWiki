## Planowanie instalacji Smart Home

Dobrze zaplanowana instalacja sprawia, że im więcej elementów uwzględnisz już na etapie projektu,
tym łatwiejsza i tańsza będzie późniejsza rozbudowa systemu Smart Home.

### Do planowania można wykorzystać:
- Excel
- LibreOffice Draw,
- klasyczne rzuty budynku

## Podział projektu:

Podczas planowania warto przeanalizować każdy z niżej wymienionych punktów:

- Obwody oświetlenia AC
- Obwody oświetlenia LED
- Obwody sterowane / gniazdka
- Rolety / żaluzje / markizy
- Bramy / furtki / drzwi
- Ogrzewanie / Chłodzenie / HVAC / Rekuperacja / Czujniki temperatury / Jakości powietrza
- Panele sterowania / Tablety
- Stacja pogodowa
- Podlewanie ogrodu
- Multimedia / Audio / Smart głośniki z analizą głosu
- Alarm / Czujniki: ruchu, obecności, pożaru, zalania / zawory odcięcia wody
- Sieć LAN / Sieć WIFI / Przyłącze światłowodu
- Kamery / Monitoring
- Automatyka techniczna / Pompy / Hydrofory / Sterowanie energią
- Fotowoltaika / Magazyny energii
- Ładowarka do auta elektrycznego
- Rozdzielnice / Szafy RACK

:::tip
Na samym początku warto wstępnie określić ilość elementów w danej grupie, np. 25 świateł AC, 6 rolet, 3 bramy,
5 sekcji sterowania ogrzewanie + czujniki, 2 smart gniazdka, alarm ruch każdy pokój + zalanie kuchnia i łazienka,
PV + stacja ładowania.
:::

### Obwody oświetlenia AC

Sterowanie klasycznym oświetleniem 230V AC.

**Funkcje:**
- Włącz / wyłącz obwody 230V
- Sceny świetlne
- Harmonogramy
- Integracja z czujnikami ruchu, obecności i zmierzchu
- Symulacja obecności domownika

---

### Obwody oświetlenia LED

Sterowanie oświetleniem LED: WHITE,CC,RGB,RGBW

**Funkcje:**
- Ściemnianie PWM
- Sceny świetlne np. w zależności od pory dnia, zachowania lub specjalne np. party
- Integracja z automatyzacją
- Symulacja obecności domownika

---

### Obwody sterowane / gniazdka

Sterowanie gniazdkami i odbiornikami energii.

**Funkcje:**
- Zdalne sterowanie
- Harmonogramy
- Pomiar energii (opcjonalnie)

---

### Rolety / żaluzje / markizy

Sterowanie osłonami okiennymi.

**Funkcje:**
- Góra / dół / stop
- Pozycjonowanie procentowe
- Pozycjonowanie kąta otwarcia dla żaluzji
- Automatyka pogodowa
- Ochrona przed przegrzaniem
- Ochrona przed hałasem
- Ochrona domu przed włamaniem

---

### Bramy / furtki / drzwi

Sterowanie dostępem do budynku.

**Funkcje:**
- Otwórz / zamknij
- Kontrola dostępu
- Zdalne otwarcie dla kuriera

---

### HVAC / ogrzewanie / chłodzenie / rekuperacja / czujniki

Sterowanie klimatem budynku.

**Funkcje:**
- Ogrzewanie budynku
- Czujniki temperatury
- Ogrzewanie ciepłej wody, grzanie zasobnika na życzenie
- Wentylacja pomieszczeń np. łazienka
- Ogrzewanie strefowe
- Klimatyzacja
- Rekuperacja
- Monitoring CO2 / wilgotności

---

### Panele sterowania / tablety

Interfejs użytkownika systemu.

**Funkcje:**
- Sterowanie całym budynkiem
- Widoki pomieszczeń
- Sceny
- Skróty

---

### Stacja pogodowa

Zewnętrzny system pomiarowy.

**Parametry:**
- Temperatura
- Wilgotność
- Wiatr
- Nasłonecznienie
- Opady
- Automatyka rolet
- HVAC
- Logika pogodowa

---

### Podlewanie ogrodu

Automatyczne systemy nawadniania.

**Funkcje:**
- Sterowanie zaworami
- Harmonogramy
- Czujniki wilgotności gleby

---

### Multimedia / audio / smart głośniki

System audio i komunikacji głosowej.

**Funkcje:**
- Multi-room audio
- Sterowanie głosowe
- Komunikaty systemowe
- Komunikaty alarmowe

---

### Alarm / czujniki / bezpieczeństwo

System bezpieczeństwa budynku.

**Czujniki:**
- Ruchu
- Obecności
- Dymu / pożaru
- Zalania
- Alarm
- Powiadomienia
- Odcięcie wody
- Funkcja wezwania cichego alarmu

---

### Sieć LAN / WiFi / światłowód

Infrastruktura komunikacyjna systemu.

**Elementy:**
- Routery
- Switche
- Access pointy
- Światłowód

---

### Kamery / monitoring

System wizyjny.

**Funkcje:**
- Nagrywanie obrazu
- Podgląd live
- Detekcja ruchu
- Integracja alarmowa

---

### Automatyka techniczna

Sterowanie urządzeniami technicznymi.

**Urządzenia:**
- Pompy
- Hydrofory
- Zawory
- Silniki

---

### Fotowoltaika / magazyny energii

Zarządzanie energią.

**Funkcje:**
- Monitoring PV
- Zarządzanie baterią
- Bilans energii
- Optymalizacja zużycia

---

### Ładowarka do auta elektrycznego

Sterowanie EV.

**Funkcje:**
- Harmonogram ładowania
- Dynamiczne obciążenie
- Integracja PV

---

### Rozdzielnice / szafy RACK

Centralna infrastruktura instalacji.

**Elementy:**
- Rozdzielnice elektryczne
- Szafy RACK
- Sterowniki
- Zasilanie awaryjne
