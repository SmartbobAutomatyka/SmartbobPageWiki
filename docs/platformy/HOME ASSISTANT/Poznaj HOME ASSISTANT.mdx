## Platforma HOME ASSISTANT

Home Assistant to jedna z najpopularniejszych na świecie platform automatyki domowej typu open-source.
Umożliwia integrację tysięcy urządzeń różnych producentów w jednym, centralnym systemie zarządzania.

# Platforma pozwala sterować, monitorować oraz automatyzować między innymi:
- Oświetlenie
- Rolety i żaluzje
- Ogrzewanie
- Klimatyzację
- Wentylację
- Alarmy
- Monitoring
- Urządzenia IoT
- Instalacje fotowoltaiczne
- Magazyny energii

SMARTBOB współpracuje z Home Assistant jako sterownik wykonawczy, system wejść i wyjść lub moduł integracji
umożliwiając budowę zaawansowanych instalacji smart home opartych o rożne protokoły i otwarte standardy.

:::tip
Jedną z największych zalet Home Assistant jest możliwość połączenia urządzeń wielu producentów
w jeden wspólny system automatyki. Większość funkcji Home Assistant działa lokalnie,
dzięki czemu automatyzacje nie są uzależnione od działania usług chmurowych.
:::
:::warning
System Home Assistant wymaga znajomości różnych technik programowania i może być zbyt wymagający dla początkujaćego
użytkownika.
:::

## SMARTBOB + Home Assistant

SMARTBOB został zaprojektowany tak, aby możliwa była łatwa integracja z Home Assistant.
Integracja realizowana jest za pomocą projektu **ESPHome**, który jest natywnie wspierany przez Home Assistant.
Dla sterowników SMARTBOB przygotowaliśmy gotowe szablony konfiguracji ESPHome,
dzięki którym uruchomienie urządzenia jest szybkie i nie wymaga tworzenia konfiguracji od podstaw.

Proces integracji wygląda zazwyczaj następująco:

1. Pobierz odpowiedni szablon dla swojego sterownika SMARTBOB i dodaj go to ESPHOME BUILDER.
2. Uzupełnij podstawowe ustawienia sieciowe, oraz dopasuj go do swoich potrzeb
3. Skompiluj i wgraj na sterownik przez USB lub OTA.SMARTBOB
4. Dodaj serownik do HOME ASSISTANT poprzez integrację ESPHOME
